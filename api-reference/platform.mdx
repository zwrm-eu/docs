## Auth

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/auth/whoami` | The authenticated user and org memberships |
| `POST` | `/v1/auth/tokens` | Create an API token (see below) |
| `GET` | `/v1/auth/tokens` | List tokens |
| `DELETE` | `/v1/auth/tokens/{token_id}` | Revoke a token |
| `GET` | `/v1/auth/sessions` | List CLI sessions |
| `DELETE` | `/v1/auth/sessions` | Revoke all CLI sessions |
| `DELETE` | `/v1/auth/sessions/{session_id}` | Revoke one CLI session |

### Scoped tokens

`POST /v1/auth/tokens` mints an unrestricted user token by default. Pass `scopes` to mint a [capability-scoped](/agents/capabilities) token instead, bound to one organization:

```json
{ "name": "ci", "scopes": ["apps:read", "deploy"], "org": "acme", "expires_in": 31536000 }
```

An unknown scope returns `400`; an org you aren't a member of returns `403`. The key is shown once. Requests made with a scoped token outside its capabilities return `403 token is not authorized for this endpoint`.

## Credits

Prepaid credit balance and the zwrm-runtime metering ledger, in EUR. See [Credits & billing](/billing/credits). Reads are org-scoped and outside the agent-token scope.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/credits` | Balance, currency (`eur`), metering flag, low-balance flag |
| `GET` | `/v1/credits/ledger` | Ledger history, newest-first (`?before_id=`, `?limit=` 1–200) |
| `GET` | `/v1/credits/usage` | Per-agent EUR consumption (today + 7 days) |
| `GET` | `/v1/credits/pricing` | Credit-metered model prices in EUR |
| `GET` | `/v1/org/gateway-usage` | Per-model [gateway](/agents/openai-api) consumption over the last N days (`?days=`) |

Subscriptions and credit-pack purchases run through Stripe in a separate auth service (`/billing/*`), driven from the dashboard — not part of the `/v1` surface.

## Templates

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/templates` | List templates |
| `POST` | `/v1/templates` | Create/register a template |
| `GET` | `/v1/templates/{id}` | Get a template |
| `DELETE` | `/v1/templates/{id}` | Delete |
| `POST` | `/v1/templates/{id}/rebuild` | Rebuild the image |
| `PATCH` | `/v1/templates/{id}/quota` | Update template quota |
