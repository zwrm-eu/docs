## Auth

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/auth/whoami` | The authenticated user and org memberships |
| `POST` | `/v1/auth/tokens` | Create an API token (see below) |
| `GET` | `/v1/auth/tokens` | List tokens |
| `DELETE` | `/v1/auth/tokens/{token_id}` | Revoke a token |
| `GET` | `/v1/auth/sessions` | List CLI sessions |
| `DELETE` | `/v1/auth/sessions` | Revoke all CLI sessions |
| `DELETE` | `/v1/auth/sessions/{session_id}` | Revoke one CLI session |

### Scoped tokens

`POST /v1/auth/tokens` mints an unrestricted user token by default. Pass `scopes` to mint a [capability-scoped](/agents/capabilities) token instead, bound to one organization:

```json
{ "name": "ci", "scopes": ["apps:read", "deploy"], "org": "acme", "expires_in": 31536000 }
```

An unknown scope returns `400`; an org you aren't a member of returns `403`. The key is shown once. Requests made with a scoped token outside its capabilities return `403 token is not authorized for this endpoint`.

## Hosts

Host visibility and lifecycle (platform operators).

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/hosts` | List hosts |
| `GET` | `/v1/hosts/{host_id}` | Get a host |
| `POST` | `/v1/hosts/{host_id}/drain` | Drain (migrate workloads off) |
| `GET` | `/v1/hosts/{host_id}/drain-status` | Drain progress |
| `POST` | `/v1/hosts/{host_id}/drain/retry/{machine_id}` | Retry one migration |
| `POST` | `/v1/hosts/{host_id}/undrain` | Cancel draining |
| `POST` | `/v1/hosts/{host_id}/activate` | Activate a host |
| `DELETE` | `/v1/hosts/{host_id}` | Remove a host (host-admin) |

## System administration

Host-admin only.

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/system/backups` | Take a control-plane backup |
| `GET` | `/v1/system/backups` | List backups |
| `GET` | `/v1/system/backups/{backup_id}` | Get a backup |
| `DELETE` | `/v1/system/backups/{backup_id}` | Delete a backup |
| `POST` | `/v1/system/secrets/rotate` | Rotate the secrets master key |
| `GET` | `/v1/system/secrets/rotation-status` | Rotation progress |
| `POST` | `/v1/system/secrets/retire/{version}` | Retire an old key version |

Internal endpoints under `/v1/internal/*` (host-agent facing: image registry, WAL proxy, volume usage, discovery) are not part of the public API surface.
