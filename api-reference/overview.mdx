Everything the `zwrm` CLI and the dashboard do goes through the REST API under `/v1`. This reference maps the full endpoint surface; the guides explain the concepts behind each resource.

## Base URL

```
https://<platform>/v1
```

For ZWRM cloud this is your platform URL.

## Authentication

All endpoints require authentication with an API token, with a few exceptions: `GET /v1/health`, trigger ingest, `GET /v1/mcp/oauth/callback` (the MCP upstream OAuth return leg), and — when one-click launches are enabled — the launch create/status routes under `/v1/launches`.

```bash
curl -H "Authorization: Bearer <token>" https://<platform>/v1/apps
```

- `Authorization: Bearer <token>` — the standard form. The `X-API-Key: <token>` header is accepted as an alternative.
- Get a token with `zwrm auth token`, or mint one via [`POST /v1/auth/tokens`](/api-reference/platform#auth).

## Organization scoping

Every resource is scoped to an organization. Without `X-Org-ID`, list and read requests span every org you're a member of, and create operations fall back to your personal (default) org. Pass `X-Org-ID: <org-id>` to narrow the request to a single org you're a member of.

## Rate limits

Requests are rate-limited per token. Expensive operations (deploys, run dispatch, session creation, sandbox creation, backups) have stricter limits than plain reads.

## Errors

Errors return JSON with a short description and the HTTP status repeated as an integer `code`:

```json
{ "error": "Not found", "message": "No app with that ID", "code": 404 }
```

`error` and `code` are always present. `message` (extra detail) may be absent, and some errors also carry a machine-readable `error_code` string.

The [OpenAI-compatible endpoints](/agents/openai-api) are the exception — they render errors in the OpenAI wire shape.

## Streaming conventions

| Transport | Used by |
|-----------|---------|
| **SSE** (`text/event-stream`) | [Session events](/api-reference/runs-sessions#session-events) with `?follow=true` |
| **WebSocket** | Machine/app [log streaming](/api-reference/apps#logs), the agent [terminal](/api-reference/agents#terminal) |

## Health

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/v1/health` | Liveness probe (no auth) |
| `GET` | `/v1/status` | Platform status for the authenticated caller |
