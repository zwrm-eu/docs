Secrets are encrypted at rest and never returned by the API — list responses contain names, versions, and status only. [Agent secrets](/agents/secrets) use the app endpoints via the agent's backing app.

## App secrets

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/apps/{app_id}/secrets` | Set (stage) a secret |
| `GET` | `/v1/apps/{app_id}/secrets` | List secrets (names and metadata only) |
| `POST` | `/v1/apps/{app_id}/secrets/deploy` | Deploy staged secrets to running machines |
| `DELETE` | `/v1/apps/{app_id}/secrets/{name}` | Delete a secret |

## Global (org) secrets

Inherited by every app and agent in the organization. See the [Global Secrets guide](/secrets).

| Method | Path | Description |
|--------|------|-------------|
| `POST` | `/v1/org/secrets` | Set an org-wide secret |
| `GET` | `/v1/org/secrets` | List org-wide secrets |
| `DELETE` | `/v1/org/secrets/{name}` | Delete an org-wide secret |
