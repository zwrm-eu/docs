## Global flags

These flags are available on every command:

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--config` | string | `~/.zwrm/config.toml` | CLI configuration file path |
| `--api-url` | string | `https://zwrm.io` | Control plane API URL |
| `--verbose`, `-v` | bool | `false` | Enable verbose output |

---

## `zwrm init`

Initialize a new `zwrm.toml` configuration file.

```bash
zwrm init [--name <name>] [--dockerfile <path>] [--no-prompt]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--name` | string | current directory name | Application name |
| `--dockerfile` | string | auto-detected | Dockerfile path |
| `--no-prompt` | bool | `false` | Use defaults without prompting |

---

## `zwrm deploy`

Build and deploy the application. [Guide →](/apps/deploy)

```bash
zwrm deploy [--app <name>] [--context <dir>] [--force-build] [--replicas <n>]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--app` | string | from `zwrm.toml` | Application name |
| `--context` | string | `.` | Build context directory |
| `--force-build` | bool | `false` | Bypass build cache |
| `--replicas` | int | `1` | Number of VM instances |

## `zwrm destroy`

Destroy machines or the entire application. [Guide →](/apps/destroy)

```bash
zwrm destroy [--app <name>] [--machine <id>] [--all] [--force]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--app` | string | from `zwrm.toml` | Application name |
| `--app-id` | string | — | Application UUID |
| `--machine` | string | — | Destroy a specific machine (prefix match) |
| `--all` | bool | `false` | Also destroy the app |
| `--force`, `-f` | bool | `false` | Skip confirmation |

## `zwrm ssh`

SSH into a running VM. [Guide →](/apps/ssh)

```bash
zwrm ssh [machine-id] [--app <name>] [--direct] [--user <user>]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--app` | string | from `zwrm.toml` | Application name |
| `--app-id` | string | — | Application UUID |
| `--machine` | string | — | Machine ID (alternative to positional) |
| `--direct` | bool | `false` | Direct connection (host access only) |
| `--user` | string | — | SSH user override |

Manage encrypted application secrets. [Guide →](/apps/secrets)

```bash

zwrm secrets set <NAME>=<VALUE>
```

### `zwrm secrets list`

```bash
zwrm secrets list [--app <name>]
```

### `zwrm secrets unset`

```bash
zwrm secrets unset <NAME> [--app <name>]
```

### `zwrm secrets add`

```bash
zwrm secrets add --from-file <path> [--app <name>]
```

All subcommands accept `--app` and `--app-id`.

## `zwrm volumes`

Manage persistent volumes. [Guide →](/apps/volumes)

### `zwrm volumes create`

```bash
zwrm volumes create <name> [--size <mb>] [--mount <path>] [--app <name>]
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--size` | int | `1024` | Volume size in MB |
| `--mount` | string | `/data` | Mount point in the VM |
| `--no-sync` | bool | `false` | Don't update zwrm.toml |

### `zwrm volumes list`

```bash
zwrm volumes list [--app <name>]
```

### `zwrm volumes destroy`

```bash
zwrm volumes destroy <name> [--force] [--no-sync]
```

### `zwrm volumes limits`

```bash
zwrm volumes limits
```

All subcommands accept `--app` and `--app-id`.

## ID prefix matching

Many commands accept machine, route, or database IDs. You don't need to type the full UUID — just enough characters to uniquely identify the resource:

```bash
zwrm ssh abc1          # matches machine with ID starting with "abc1"
zwrm destroy --machine ab12
zwrm routes delete 7f3
```

If the prefix matches multiple resources, the command fails with an error listing the ambiguous matches.
