<Warning>
Managed PostgreSQL is currently in **beta**. Do not run production workloads — data loss may occur during this phase.
</Warning>

ZWRM provides managed PostgreSQL databases running in dedicated Firecracker VMs. Each database gets its own isolated environment with persistent storage.

## Create a database

```bash
zwrm postgres create <name>
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--size` | string | `small` | Size preset: `small`, `medium`, or `large` |
| `--database` | string | instance name | Initial database name — defaults to the instance name, sanitized to a valid Postgres identifier (e.g. `my-db` → `my_db`) |

After creation, you'll see the connection credentials, connection strings (internal and external), and host information.

<Tip>Run `zwrm postgres presets` to see what each size includes.</Tip>

### Example

```bash
zwrm postgres create my-db --size medium
```

## Connect to a database

```bash
zwrm postgres connect <name>
```

Shows connection details and ready-to-use `psql` commands. The database must be running.

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--direct` | bool | `false` | Return the raw Postgres connection (`:5432`), bypassing the pooler |

When a connection pooler (PgBouncer) is enabled for the database, the connection string routes through it by default. Use `--direct` for admin tasks that need session-level features the pooler doesn't support in transaction mode.

## List databases

```bash
zwrm postgres list
```

Shows all databases with their ID, name, status, host, size, replica count, backup state, and creation time. The `BACKUP` column reads `off` when WAL archiving is disabled, `ok` when archiving is on and the database is recoverable, and `MISSING` when archiving is on but no recoverable backup exists.

## Stop and start

Stop a database (data is preserved):

```bash
zwrm postgres stop <name>
```

Start it again:

```bash
zwrm postgres start <name>
```

## Destroy a database

```bash
zwrm postgres destroy <name>
```

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--force`, `-f` | bool | `false` | Skip confirmation prompt |

<Warning>Destroying a database permanently deletes all data. This cannot be undone.</Warning>

## Size presets

View available presets and their resources:

```bash
zwrm postgres presets
```

Each preset defines vCPUs, memory, and storage allocation.
