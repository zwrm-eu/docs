## Usage

```bash
zwrm ssh [machine-id] [flags] [-- command [args...]]
```

Open an SSH session to a running VM, or run a single command on it.

## Arguments

| Argument | Type | Description |
|----------|------|-------------|
| `machine-id` | string (optional) | Machine to connect to (prefix matching supported) |

## Flags

| Flag | Type | Default | Description |
|------|------|---------|-------------|
| `--app` | string | from `zwrm.toml` | Application name |
| `--app-id` | string | — | Application UUID |
| `--machine` | string | — | Machine ID (alternative to positional argument) |
| `--direct` | bool | `false` | Connect directly to the VM IP |
| `--user` | string | — | SSH user override |
| `--command`, `-C` | string | — | Remote command to run (alternative to `-- command`) |
| `--tty`, `-t` | bool | `false` | Force PTY allocation (e.g. for `-- top`) |
| `--no-tty`, `-T` | bool | `false` | Disable PTY allocation |

## Running a remote command

Everything after `--` is executed on the VM instead of opening an interactive shell: stdout/stderr stream back, stdin is forwarded, and the CLI exits with the remote command's exit code (255 means the SSH connection itself failed).

```bash
zwrm ssh -- uptime                       # run a command, exit with its code
zwrm ssh --app myapp -- bash -lc 'cd /app && python3 task.py'
zwrm ssh -C 'cd /app && ls -la'          # command as a single flag value
echo 'print(1)' | zwrm ssh -- python3 -  # feed a script via stdin
```

A single token after `--` is passed to the remote shell verbatim, so shell syntax works; with several tokens each one is quoted, so the remote command sees exactly the arguments you typed.

## Connection modes

### Proxy mode (default)

The default mode connects through ZWRM's SSH proxy using short-lived certificates. This works from anywhere — no direct network access to the VM is required.

```bash
zwrm ssh
zwrm ssh abc123
```

ZWRM automatically:
1. Creates a dedicated SSH key at `~/.ssh/zwrm_ed25519` (if it doesn't exist).
2. Requests a short-lived certificate from the server.
3. Connects through the proxy.

### Direct mode

Direct mode connects straight to the VM's IP address. This is only available when you have host-level network access.

```bash
zwrm ssh --direct
```

## Examples

SSH into the first available machine:

```bash
zwrm ssh
```

SSH into a specific machine by ID prefix:

```bash
zwrm ssh abc123
```

Connect directly (host access required):

```bash
zwrm ssh --direct --machine abc123
```
